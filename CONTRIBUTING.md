# Contributing

Thank you for helping build Workspace Orchestrator. Begin by reading `AGENTS.md`, `PROJECT_STATUS.md`, and the active milestone in `docs/ROADMAP.md`.

Discuss substantial features before implementation. Keep pull requests focused, preserve the component boundaries, and do not introduce future-milestone functionality through an unrelated change.

## Development checklist

1. Create a focused branch.
2. Add or update tests without launching real applications or URLs.
3. Run `swift test`.
4. Run the exact app build in `AGENTS.md`.
5. Update relevant documentation and `PROJECT_STATUS.md`.
6. Review the diff for secrets, absolute personal paths, generated output, and unsafe process behavior.

Contributions are accepted under Apache License 2.0. Participation must follow the Code of Conduct. Security issues must be reported privately according to `SECURITY.md`, not through a public issue.
