# App icon

The V1 release-candidate icon uses three workspace panes converging on one control point. It represents deterministic orchestration: separate tools and actions becoming one reviewed workspace run. The obsidian, ice-cyan, and restrained violet palette matches the in-app design system.

The checked-in high-resolution master was generated with OpenAI's built-in image-generation tool, then resized locally into the required macOS asset-catalog variants. The source prompt was:

> Create an original macOS app icon for Workspace Orchestrator. Use three offset workspace panes or command tiles converging into one precise central activation point. Use premium native macOS icon styling, crisp geometric 3D relief, a deep obsidian and graphite base, ice-cyan accents, and a restrained violet accent. Keep a strong silhouette that remains legible at 16 pixels. Use no text, trademarks, Apple logo, gear, rocket, magic wand, robot, cloud, play button, target, watermark, or excessive glow.

The original generated file is preserved as `AppIcon-master.png`; `AppIcon.appiconset` contains the derived production sizes.
